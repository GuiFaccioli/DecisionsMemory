# 0001 — Establish DecisionMemory scope

**Status:** Accepted

## Decision

The project is named **DecisionMemory**. It records durable technical knowledge created during real development work: decisions, discoveries, bug fixes, trade-offs, and non-obvious techniques.

DecisionMemory is not a transcript of every conversation or session. Passing mentions, generic explanations, trivial documentation, and information with no meaningful novelty are excluded.

## Rationale

The intended outcome is a practical technical memory for each application: a developer should be able to see what was decided, why it changed, and what is true now.

## Consequences

- Capture is selective and evidence-based.
- Entries represent knowledge, rather than sessions.
- The project remains in design; this decision does not introduce an implementation.
